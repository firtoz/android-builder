# Android Builder

Independent MIT-licensed Android build tooling. Keep all source, docs, examples and tests generic: no client application imports, identities, credentials or account-specific configuration.

Use released Jetski. Provider credentials stay on the controller; signing is separate. Preserve stable operations, bounded leases/logs/transfers, exact artifact verification, failed outcomes and positive owned cleanup. Never replay an uncertain build launch.

No paid hosts, public repository creation or npm publication without user authorization. Existing experiment allowances do not transfer to this project. Do not modify client repositories during extraction.

Run `npm run check` and inspect the packed artifact. Local simulated-host tests are not live provider or real Android compilation qualification. Keep those evidence boundaries explicit.
